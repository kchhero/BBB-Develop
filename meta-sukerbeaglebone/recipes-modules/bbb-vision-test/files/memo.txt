1단계: OpenCV + Rust 환경 준비
  opencv와 opencv-rust crate을 이용하여 카메라 캡처 → 물체 인식 테스트 진행


2단계: 카메라 기반 물체 탐지
  단순히 빨간색 물체 같은 고정 타겟을 HSV 컬러 필터링으로 검출
  물체의 (x, y) 좌표만 구해도 충분
  좌표 → 좌/우, 상/하 서보 각도 매핑

3단계: Vision → Servo 제어 통합
  bbb-vision-test 실행 시:
    카메라에서 프레임 캡처
    물체 중심 좌표 계산
    간단한 맵핑(x → 베이스 서보, y → 어깨 서보)
    내부에서 PCA9685 드라이버(pwm_pca9685) 호출하여 구동

4단계: 메인 앱에 통합
  OpenCV 파이프라인이 안정되면, 기존 bbb-servo-controller와 합쳐서
  웹 UI 제어
